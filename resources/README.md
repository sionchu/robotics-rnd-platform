# Curated Resources

This catalog favors official project/vendor documentation and a small number of
high-value entry points. Every entry records the provider, URL, purpose, version,
verification date, learning/application mapping, and local notes. Re-check the
support matrix before installing version-sensitive robotics or GPU software.

- `ros2.md`: ROS 2 Jazzy and TF2.
- `robotics_math.md`: Eigen and transform foundations.
- `opencv.md`: OpenCV and camera calibration.
- `rainbow.md`: official Rainbow Robotics repositories.
- `mech_mind.md`: official Mech-Eye API documentation.
- `raspberry_pi.md`: OS, remote access, and camera stack.
- `nvidia_cuda.md`: CUDA and TensorRT.
- `isaac_ros.md`, `isaac_sim.md`: accelerated ROS and simulation.
- `repositories.md`: official source/documentation hubs for the baseline tools.

Verification means the official page was reachable on the recorded date; it
does not mean the software is installed, compatible, licensed for redistribution,
or validated on this workstation.
