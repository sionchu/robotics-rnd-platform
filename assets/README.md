# Digital Twin Assets

Git may contain only small, generic assets with documented ownership and
redistribution rights. Large or proprietary CAD/USD assets remain under the
external workstation data root. Each tracked or external asset needs a manifest
with source, license, format, units, coordinate convention, version, checksum,
and storage hint.

Never place company CAD, production geometry, vendor-licensed packages, or local
cache output in this tree. See `docs/data/DATA_POLICY.md`.
