## Included

- reusable external research intake, registries, evaluation templates, backlog,
  and technology decisions;
- current official rbpodo, rbpodo_ros2, RB documentation, changelog/examples,
  compatibility, issue-risk, and provenance review;
- generic command lifecycle, connection/fault/state/capability models;
- isolated optional rbpodo backend, safe Rainbow adapter, deterministic fake,
  fault injection, SI/Euler/quaternion mapping, and conservative resync lockout;
- redacted JSONL command journal, ReplayRobot, application/HMI service, hardware-
  free RB Control Lab CLI/demos, and experiments 013–016;
- contract, mapping, failure, replay, architecture, IP, and release gates.

## Not validated or included

No RB hardware/controller/network, live connection, live state, I/O write, motion,
stop behavior, timing, compatibility, ROS graph, or production application was
validated. The CLI exposes no live path. Raspberry Pi hardware work from v0.2.1
remains `NOT_RUN_HARDWARE_UNAVAILABLE`; this software-only release does not tag
or promote that physical milestone.

The first future RB hardware task is LEVEL 1 read-only validation only. The
recommended next research milestone without hardware is the Mech-Eye 3D Vision Lab.
