# External Research Registry

External technologies enter the platform through a recorded question, verified
sources, license and maintenance review, a bounded reproduction, a decision, and
an adapter or rejection boundary. `docs/research/EXTERNAL_RESEARCH_INTAKE.md` is
the normative process.

- `intake/` contains source-type guidance.
- `registry/` contains machine-readable reviewed facts.
- `evaluations/` contains reusable evaluation templates.
- `decisions/` links evidence to platform dispositions.
- `backlog.yaml` holds questions, not unreviewed dependencies.

Temporary clones belong in ignored `.external/` or `/tmp`; external source is
never copied into this repository merely because it was inspected.
