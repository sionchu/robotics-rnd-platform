# Hardware Research Boundaries

Hardware directories contain planning, safety, interface, setup, and validation
notes—not credentials, addresses, serials, calibration results, vendor binaries,
or private captures. Every live test must be opt-in, versioned, reversible, and
separate from the hardware-free generic suite.

- `rainbow`: future RB controller adapter and control lab.
- `mech_mind`: distinct direct camera and external vision-provider paths.
- `raspberry_pi`: Pi 4 deployment and camera benchmark target.
- `cameras`, `jetson`, `sensors`: future selection/validation records.
