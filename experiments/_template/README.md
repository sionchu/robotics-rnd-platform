# Experiment: replace with a precise title

Complete before running:

- Question: one specific unknown.
- Hypothesis: a falsifiable expected result.
- Environment: OS, interpreter/compiler, packages, hardware, seed, dataset/fixture provenance.
- Reproduction: exact setup and commands.
- Metrics: definitions, units, sample count, acceptance threshold.
- Observations: raw or linked results without interpretation.
- Conclusion: evidence-based answer and limitations.
- Decision: `discard`, `continue`, or `package`.

Generated/binary results stay ignored. Track small text summaries and plots only
after checking privacy, licensing, and size.
