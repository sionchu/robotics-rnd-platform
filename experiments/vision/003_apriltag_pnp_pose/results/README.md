# Results

Four exact-corner cases passed near numerical precision. Maximum translation
error was `4.96242e-11 m`, orientation error was `0 deg`, and maximum mean
reprojection error was `6.03653e-9 px`.

The integrated raster/detection case measured `5.04749 mm` translation error,
`1.13331 deg` orientation error, and `0.29425 px` mean reprojection error,
demonstrating that near-zero solver residual is not equivalent to physical pose
accuracy.
